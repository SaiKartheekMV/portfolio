# Interstellar Portfolio — Venkata Sai Kartheek Mulukutla

> **"Mankind was born on Earth, it was never meant to die here."**  
> An interactive, responsive, cosmic Interstellar-themed portfolio built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS**.

---

## 🌌 Features

- **Gargantua Singularity & Accretion Halo**: Mathematical SVG/CSS gravitational lensing visual with relativistic glow and photon sphere.
- **Interactive 3D Warp Starfield**: 60 FPS HTML5 Canvas engine with depth projection, mouse gravitational drift, and one-click Warp Speed acceleration.
- **Synthesized Cosmic Audio (Web Audio API)**: Zero external audio file dependencies. Browser-generated 55 Hz Gargantua drone, sonar chirps, and warp sweeps.
- **Relativistic Time Dilation Console**: Interactive Miller's Planet time dilation calculator comparing Earth time vs. gravitational horizon time.
- **Spacecraft Command Console (CLI)**: Interactive embedded terminal running commands (`help`, `projects`, `skills`, `trajectory`, `quote`, `resume`, `warp`).
- **Planetary Mission Logs**: Deep-dive telemetry dossiers for **SwiftPath AI**, **SecurePay**, and **Pulmo-Track** with metrics, architecture diagrams, and GitHub links.
- **5-Dimensional Tesseract Matrix**: Interactive category filtering and reactor power bars for programming languages, AI/ML, Agentic systems, backend frameworks, and cloud infrastructure.
- **Full Vercel & Edge Optimization**: Pre-rendered static pages (`○ (Static)`) for instantaneous First Contentful Paint (FCP) and near-zero Total Blocking Time.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS
- **Graphics & Audio**: HTML5 Canvas, Web Audio API
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Create optimized production build
npm run build

# Start production server
npm start
```
